# Bondis Argentina — descargas

Versiones de prueba de la app Android **Bondis Argentina** (colectivos de toda la Argentina).

**[⬇️ Descargar la última versión (BondisArgentina.apk)](https://github.com/franco-valenzuela/bondis-argentina-releases/releases/latest/download/BondisArgentina.apk)**

- Al instalar, Android pide permitir "instalar apps desconocidas". Es una versión de prueba, no de Play Store.
- Una vez instalada, la app avisa sola cuando hay una versión nueva y se actualiza desde adentro.
- Datos: Ciudad de Mendoza – Datos Abiertos (CC BY 4.0) y © OpenStreetMap contributors (ODbL).

Este repositorio sólo contiene las versiones publicadas; el código está en un repositorio privado.
